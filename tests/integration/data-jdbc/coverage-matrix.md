# Helidon Data JDBC integration test coverage matrix

This matrix tracks integration test coverage for the Helidon Data JDBC provider.
It is intended for review and gap analysis, not as a replacement for test source
comments or assertions.

Last reviewed: 2026-08-19

## Legend

| Marker | Meaning |
| --- | --- |
| Yes | The test exists and runs for this database. |
| Yes, DB-specific | The test exists with database-specific expected values or setup. |
| H2 only | The test is intentionally provider-internal or reference-path H2 coverage. |
| Planned | Coverage is planned but not implemented in this matrix yet. |
| N/A | The scenario is not intended to run for this database. |
